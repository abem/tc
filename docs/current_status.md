## 技術仕様

### システム構成
```
transcribe_audio/
├── scripts/core/
│   ├── main.py              # メイン処理
│   ├── transcription_engine.py  # 文字起こしエンジン
│   ├── audio_loader.py      # 音声ファイル読み込み
│   ├── text_formatter.py    # テキスト整形
│   └── output_handler.py    # 出力処理
├── transcriber.py           # WhisperTranscriber（タイムスタンプ機能）
├── config/
│   └── config.yaml         # 設定ファイル
└── output/                 # 出力ディレクトリ
```

### 主要クラス
- **TranscriptionEngine**: 文字起こし処理の統合管理
- **WhisperTranscriber**: Whisperモデルによる文字起こし
- **AudioLoader**: 音声ファイルの読み込み・ダウンロード
- **TextFormatter**: テキストの整形・フォーマット
- **OutputHandler**: 結果の保存・アップロード
