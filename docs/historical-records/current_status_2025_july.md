## 🚀 **利用可能なコマンド**

### **基本的な文字起こし**
```bash
# 日本語音声（Google Drive/YouTube）
./tc --language ja

# 英語音声（Google Drive/YouTube）
./tc --language en

# ローカルファイル処理
./exec_local.sh audio.wav --language ja
```

### **話者分離付き文字起こし**
```bash
# 日本語音声の話者分離
./tc --language ja --enable-diarization --max-speakers 3

# 英語音声の話者分離
./tc --language en --enable-diarization --max-speakers 2

# ローカルファイルでの話者分離
./exec_local.sh audio.wav --enable-diarization --max-speakers 2
```

### **🆕 開発・テスト用コマンド**
```bash
# 包括的品質チェック
./scripts/pre_check.sh

# 全テスト実行
python -m pytest tests/ -v

# コード品質チェック
black . --check
flake8 .
isort . --check-only
mypy .

# GPU監視
./scripts/simple_gpu_monitor.sh
```
