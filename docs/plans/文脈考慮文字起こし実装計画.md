# tc CLI 文脈考慮文字起こし実装計画 (2025-09開始)

## 🎯 プロジェクト概要

### 現在のベースライン（2025-08-11）
- ✅ **高品質転写**: kotoba-whisper-v2.2で日本語95%+精度
- ✅ **セグメント処理**: 30秒チャンク・タイムスタンプ付与
- ✅ **統一システム**: UnifiedTranscriberによる一貫した処理

- 🗣️ **話者文脈**: 話者別語彙・表現パターン学習
