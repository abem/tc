# 文字起こし結果における文の重複発生原因と対策分析

本ドキュメントでは、音声ファイルの分割およびWhisperモデルの動作によって発生する「同一文の重複出力」現象について、
その技術的要因を分析し、改善案と検証計画を提示する。

## 1. 主な原因

### 1.1 音声の分割処理
- **チャンク分割の重複**
  - 現在の実装では、30秒ごとに音声ファイルを自動分割（transformersベースWhisperモデルの推奨方式）
  - 分割時にオーバーラップ領域が存在しない場合、文脈の連続性が失われるため、同一内容の再出力が発生しやすい

### 1.2 モデルの特性
- **Whisperモデルの動作**
  - モデルが文脈を理解するために前後の音声を参照
  - 分割されたチャンクの境界で文脈が失われる
  - 同じ内容を複数回再出力する可能性がある

### 1.3 音声の特性
- **無音部分の処理**
  - 無音部分がチャンクの境界に存在する場合
  - モデルが無音部分を文の区切りとして認識
  - 同じ内容を別の文として再出力する可能性がある

## 2. 技術的な詳細

### 2.1 チャンク処理の実装
- `transcriber.py`等で30秒ごとに音声を分割し、各チャンクをtransformersベースWhisperで逐次推論
- 分割時にオーバーラップを設けることで文脈の連続性を担保可能

### 2.2 文字起こし処理の実装
- 各チャンクごとに`WhisperForConditionalGeneration`＋`AutoProcessor`で推論
- spaCy GiNZAで文区切り・整形を行い、重複や断片の除去も後処理で実施

## 3. 影響範囲

### 3.1 発生しやすい状況
- 長い音声ファイルの処理時
- 文の区切りがチャンク境界と一致する場合
- 無音部分が長い音声ファイル

### 3.2 影響を受ける機能
- 文字起こしの精度
- 出力ファイルの可読性
- 後処理（要約など）の精度

## 4. 改善案

### 4.1 短期的な対策
- チャンクサイズの調整
  - 文の区切りを考慮したサイズ設定
  - 無音部分を基準とした分割

### 4.2 中長期的な対策
- オーバーラップ処理の導入
  - チャンク間に重複領域を設ける
  - 重複部分の文字起こし結果を統合
- 文脈認識の強化
  - 前後のチャンクの情報を保持
  - 文脈を考慮した文字起こし
- GiNZA等による文区切り・重複除去の後処理強化

## 5. 検証方法

### 5.1 テストケース
- 異なるチャンクサイズでのテスト
- 様々な長さの音声ファイルでのテスト
- 無音部分の長さを変えたテスト

### 5.2 評価指標
- 重複発生率
- 文字起こしの精度
- 処理時間への影響

## 6. 未解明の要因と追加対策

### 6.1 Whisperのセグメント出力による影響
- **セグメント粒度の問題**
  - Whisperは音声を数秒単位のセグメントに分割
  - 各チャンク処理で`segment["text"]`を前後関係なく逐次保存
  - 出力単位が人間の感覚より細かく、再掲が目立ちやすい

- **対策案**
  - 同一セグメントの`start`/`end`値がほぼ一致する場合はスキップするフィルタ導入
  - セグメント間の時間間隔を考慮した統合処理の実装

### 6.2 音声先頭処理による影響
- **先頭部分の誤認識**
  - Whisperがチャンク先頭を「準備的な無音・雑音」と誤認
  - 前回と同じ文を再出力する可能性

- **対策案**
  - チャンク先頭の無音部分長さの強調
  - VAD（Voice Activity Detection）との併用検討
  - 先頭部分の特別な処理ルーチン導入

### 6.3 ポストプロセスによる影響
- **出力の類似性評価の不足**
  - 文字列の類似比較（Levenshtein距離など）による重複検出
  - 意味上ほぼ同じ文の繰り返しを除去

- **対策案**
  - 近似一致ベースの重複排除モジュール追加
  - 文脈を考慮した重複判定ロジックの実装
  - 出力結果の品質評価指標の導入

### 6.4 音声データ特性による影響
- **音源自体の繰り返し**
  - 話者による同じ文の繰り返し読み上げ
  - 音声データの構造的な繰り返し

- **対策案**
  - 元音声と出力結果の照合による原因切り分け
  - 話者ごとの特性を考慮した処理の導入
  - 音声データの前処理による繰り返しパターンの検出

## 7. 総合的な改善方針

### 7.1 優先度の高い対策
1. セグメント出力の最適化
2. チャンク先頭処理の改善
3. 重複除去モジュールの実装

### 7.2 中長期的な取り組み
1. VADとの統合
2. 音声データ特性の分析
3. 出力品質の自動評価

### 7.3 検証計画
1. 各対策の効果測定
2. 処理時間への影響評価
3. 出力品質の定量的評価
