### 🚀 技術仕様・実装詳細

#### 使用技術スタック
- **話者分離**: pyannote.audio v3.3.2（最新版）
- **モデル**: pyannote/speaker-diarization-3.1（HuggingFace）
- **統合**: UnifiedTranscriber経由でWhisperと完全統合
- **認証**: HuggingFaceトークンによる自動認証
- **環境**: uv環境・Python 3.11+・CUDA対応

#### 実装方法・アーキテクチャ
```bash
# 基本的な話者分離付き転写
./tc audio.wav --enable-diarization

# YouTube動画の話者分離
./tc "https://youtube.com/watch?v=abc123" --enable-diarization

# 最大話者数制限
./tc audio.wav --enable-diarization --max-speakers 3
```

#### 内部処理フロー
1. **音声前処理**: ffmpeg自動変換・正規化
2. **話者分離実行**: pyannote.audio Pipeline適用
3. **区間抽出**: 話者別セグメント分離
4. **Whisper統合**: 各区間でkotoba-whisper-v2.2実行
5. **結果統合**: タイムスタンプ+話者ID+テキスト結合
6. **出力保存**: TXT・JSONフォーマット対応

#### 出力例
```
[00:00:12] SPEAKER_00: こんにちは、今日はお忙しい中ありがとうございます。
[00:00:16] SPEAKER_01: いえいえ、こちらこそよろしくお願いします。
[00:00:20] SPEAKER_00: それでは早速、今回のプロジェクトについてお伺いします。
```

## 📋 運用・利用ガイド

### 必要な事前設定
1. **HuggingFaceトークン取得**: [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
2. **モデルアクセス許可**: [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)で「Agree and access」
3. **環境変数設定**: `export HUGGINGFACE_TOKEN=hf_your_token_here`

### 最適な使用条件
- **音声品質**: クリアな音声・ノイズ少ない環境
- **話者数**: 2-6人（推奨は2-4人）
- **音声長**: 2時間以内（長時間は分割推奨）
- **言語**: 日本語・英語（単一言語推奨）

### トラブルシューティング
- **認証エラー**: HuggingFaceトークン再確認
- **精度低下**: max-speakers調整・音声品質改善
- **メモリ不足**: CPU自動切り替え・音声分割
- **処理速度**: GPU使用確認・長時間音声分割
