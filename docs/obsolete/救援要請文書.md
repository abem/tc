# 救援要請文書

## 1. 問題の概要

### 1.1 発生している問題
- 文字起こし結果が空になる
- 文字起こし結果が「テ」の繰り返しになる
- 文字起こし結果が特殊文字の羅列になる
- 文字起こし処理が無限ループに陥る

### 1.2 影響範囲
- 音声ファイルの文字起こし機能
- 文字起こし結果の保存
- Google Driveへのアップロード機能

### 1.3 発生条件
- すべての音声ファイルで発生
- 特に長い音声ファイルで顕著
- GPUメモリ使用量が高い場合に発生しやすい

## 2. 技術的な詳細

### 2.1 使用している技術スタック
- Python 3.11
- PyTorch 2.2.0
- Transformers 4.38.2
- Whisper (drewschaub/whisper-large-v3-japanese-4k-steps)
- NVIDIA GeForce RTX 4080 SUPER

### 2.2 関連するコード
- `transcriber.py`: 文字起こしの主要ロジック
- `transcribe_audio.py`: メイン処理
- `exec.sh`: 実行スクリプト

### 2.3 エラーログ
```
[INFO] 文字起こしを開始: test_audio.wav
The attention mask is not set and cannot be inferred from input because pad token is same as eos token.
[INFO] 文字起こしが完了しました
[INFO] 文字起こし結果を保存しました: 250508_1307_transcription.txt
```

## 3. 根本原因の分析

### 3.1 主要な問題点
1. Attention Maskの問題
   - パッドトークンとEOSトークンが同じ
   - Attention Maskが自動推論できない
   - 入力の処理が不適切

2. トークナイザーの設定問題
   - 特殊文字の処理が不適切
   - 日本語トークンの処理が不完全
   - パディングの設定が不適切

3. モデルの初期化問題
   - デコーダー設定が不完全
   - 生成設定が不適切
   - メモリ管理が非効率

### 3.2 技術的な詳細
| 問題点 | 影響 | 解決方法 |
|--------|------|----------|
| Attention Mask | 特殊文字出力 | 明示的な設定が必要 |
| トークナイザー | 文字化け | 適切な設定が必要 |
| モデル初期化 | メモリ問題 | 完全な設定が必要 |

## 4. 解決策

### 4.1 必須の修正
1. Attention Maskの明示的な設定
```python
attention_mask = torch.ones_like(input_features[:, :, 0], dtype=torch.long)
```

2. トークナイザーの適切な設定
```python
self.processor.tokenizer.pad_token = self.processor.tokenizer.eos_token
self.processor.tokenizer.padding_side = "right"
```

3. モデル初期化の完全な設定
```python
self.model.generation_config.pad_token_id = self.processor.tokenizer.pad_token_id
self.model.generation_config.eos_token_id = self.processor.tokenizer.eos_token_id
```

### 4.2 期待される効果
- 特殊文字の出力を防止
- 日本語文字起こしの正常化
- メモリ使用量の最適化
