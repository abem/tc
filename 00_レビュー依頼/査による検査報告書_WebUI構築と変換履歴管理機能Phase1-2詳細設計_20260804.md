## 2. 初回検査：不合格2件の指摘

### 指摘1: DB設計書§5-2「統合設計方針」の技術的誤り

**指摘内容**: 「GDriveアップロードtry/exceptブロックの直後（L236相当）。`full_url`（取得できた場合）が
すべてスコープ内に揃っているため、追加の値受け渡し設計が不要」との記載は誤り。

**検証コマンドと結果**:
```
$ sed -n '205,236p' transcribe.py
```
実測により、`full_url` は `save_results()` 内の `if resolution.source_type in {"youtube", "gdrive"}:`
分岐の内側でのみ代入される変数であることを確認。`resolution.source_type == "local"`
の場合はこの分岐が実行されず `full_url` は未代入のままとなり、分岐外で参照すると
Pythonの関数スコープ規則上 `UnboundLocalError` が発生する（ローカルファイル入力の全ケースで発生）。

**是正指示**: `save_results()` 内で GDrive アップロードの try ブロックへ入る前に
`full_url: Optional[str] = None` を初期化する設計へ修正すること。

### 指摘2: WebUI設計書§3-1「入力フォーム」の技術的誤り

**指摘内容**: 「`config/config.yaml` の `system.allowed_file_types` と一致する拡張子のみ許可」との
記載中、当該キーは `config.yaml` に存在しない。

**検証コマンドと結果**:
```
$ grep -n "allowed_file_types\|^system:" config/config.yaml
（該当0件）
```
`config.yaml` に `system:` セクション・`allowed_file_types` キーはいずれも存在しないことを確認。
実体は `core/config.py` の `SystemConfig.allowed_file_types`（L163、Pythonデフォルト値であり
`config.yaml` への記載はない）。

**是正指示**: 参照先を `UnifiedConfig.system.allowed_file_types`（`core/config.py` SystemConfig
のデフォルト値）である旨に訂正し、`config.yaml` 由来と誤認させる記載を修正すること。
