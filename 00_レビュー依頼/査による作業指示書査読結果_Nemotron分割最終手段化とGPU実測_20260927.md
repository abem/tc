## 2. 是正必須1: 完了条件`OK_SILENCE_AWARE_SPLIT`が実装前から偽陽性になる

```
$ grep -q "silence\|無音" core/nemotron_engine.py && echo OK_SILENCE_AWARE_SPLIT || echo MISSING_SILENCE_AWARE_SPLIT
OK_SILENCE_AWARE_SPLIT   ← 無音区間対応の実装着手前に、すでにこの結果になる
```

原因: 前回是正（`empty_chunks`、正常終了のまま空応答を返すチャンクの検知）のログメッセージ・コメントに「無音」「silence」という単語が既に含まれている（`core/nemotron_engine.py` L295・L302）。この既存の語がヒットするため、`grep -q "silence\|無音"`は**本指示書が求める「無音区間検出による分割点調整機能」を一切実装しなくても常に真になる**。この完了条件は機能を検証していない。

**是正指示**: 無音区間検出機能に固有の識別子（例: 新設する関数名`find_silence_boundary`や、既存の`empty_chunks`関連文言とは重複しない専用のコメントタグ）を条件に用いるか、実際に呼び出し箇所が存在すること（`librosa.effects.split`等の呼び出し行の存在）を確認するgrepへ変更されたい。

## 3. 是正必須2: 回帰ゲートの類似度算出方法が指示書に明記されていない

背景記載の類似度「0.897」を査が独立に再現しようとしたところ、`difflib.SequenceMatcher`の**既定設定**（`autojunk=True`）では0.824となり、0.897には一致しなかった。`autojunk=False`を明示指定した場合のみ、`0.896551724137931`（四捨五入で0.897）と正確に一致することを確認した。

```python
difflib.SequenceMatcher(None, t71, t78).ratio()               # 既定: 0.824(一致しない)
difflib.SequenceMatcher(None, t71, t78, autojunk=False).ratio()  # 0.897(一致)
```

`autojunk`（既定`True`）は、頻出する要素をヒューリスティックに「ノイズ」として除外し、マッチングブロックの計算から外すオプションであり、繰り返しの多い日本語文（句読点・助詞等）を比較する場合、既定設定と`autojunk=False`とで結果が数十パーセント単位で変動しうることを実測で確認した（本件は0.824 vs 0.897で約7ポイント差）。

**是正指示**: 本指示書§4項目4（回帰ゲート比較スクリプト）に、類似度の算出方法を明示すること（`difflib.SequenceMatcher(None, a, b, autojunk=False).ratio()`を用いる、または他の具体的手法を明記し、その場合は「0.98以上」の基準がその手法に対して妥当であることの根拠も併記する）。今後查がこのスクリプトを繰り返し使用する前提であり、算出方法が曖昧なままでは実装者ごとに異なる基準で判定される恐れがある。
