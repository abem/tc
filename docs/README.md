# ドキュメント インデックス - 音声文字起こしシステム（tc）

## 🚀 新CLI対応システム

**推奨実行方法**: `./tc` コマンドでシンプル実行  
**環境**: uvパッケージマネージャー推奨（pip比較10倍高速）  
**特徴**: YouTube→Google Drive自動連携、設定ファイル自動読み込み
